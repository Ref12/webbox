webbox

A playground of small web apps, each in its own folder.

hexad remoteRing a hexad agent harness, open it from anywhere, and hear when a session needs you. Qwen chatChat with a Qwen model running entirely in your browser, on the GPU (WebGPU) or the CPU (WebAssembly). Speech keep-aliveTest which ways of speaking and listening (browser voice, audio, Web Audio, wake lock, microphone) keep working with the screen off, in a tab or installed. SharpLab (C# on WebAssembly)Type C# and see its syntax tree, IL, decompiled lowered C#, run output and IL verification, all computed in your browser by Roslyn on .NET WebAssembly. Share links carry the code and options. Key VaultSign in with Azure, browse your Key Vaults and show, copy and edit secrets inline in one window (device-code sign-in and secret values go through your own small CORS proxy Worker). PR viewerReview a GitHub pull request like Azure DevOps: a file tree with change badges, full-file diffs inline or side by side, review threads inline (reply, resolve, post comments or a whole review), PR lists, reviewed checkboxes and a commit picker. Public repos need no sign-in; sign in with GitHub to comment. C# interactiveA C# REPL with IntelliSense that compiles and runs in your browser on .NET WebAssembly (Roslyn, NuGet packages with #r, nothing leaves the page).
