webbox

A playground of small web apps, each in its own folder.

SharpLab (C# on WebAssembly)Type C# and see its syntax tree, IL, decompiled lowered C#, run output and IL verification, all computed in your browser by Roslyn on .NET WebAssembly. Share links carry the code and options. PR viewerReview a GitHub pull request like Azure DevOps: a file tree with change badges, full-file diffs inline or side by side, review threads inline (reply, resolve, post comments or a whole review), PR lists, reviewed checkboxes and a commit picker. Public repos need no sign-in; sign in with GitHub to comment. fuget (NuGet browser)Browse any NuGet package in your browser: its API with docs, decompiled source and the diff between versions, all on .NET WebAssembly. ILSpyThe ILSpy .NET decompiler running in your browser on WebAssembly: open or drop an assembly, browse its types and read the decompiled C#. Nothing is uploaded. Roslyn QuoterTurn C# into the Roslyn SyntaxFactory calls that build it, entirely in your browser, with options, a round-trip check and share links. MSBuild binlog viewer (preview)Open an MSBuild .binlog in your browser: the build tree, search, node details and the embedded source files, on .NET WebAssembly. Preview: logs over about 50 MB don't fit yet. C# interactiveA C# REPL with IntelliSense that compiles and runs in your browser on .NET WebAssembly (Roslyn, NuGet packages with #r, nothing leaves the page).
